# Lines98

Браузерная реализация классической игры Lines 98 на C# и Blazor WebAssembly. Проект демонстрирует разработку игрового ядра с неизменяемым состоянием, алгоритмами поиска пути и линий, автоматическими тестами и отдельным пользовательским интерфейсом.

## Возможности

- Поле 9×9 и шарики семи цветов; новая партия начинается с пяти шариков без готовых линий.
- Перемещение по свободному пути, выбор шарика и подсветка доступных клеток.
- Удаление линий из пяти и более шариков по горизонтали, вертикали и обеим диагоналям. Пересечения учитываются один раз.
- Одно очко за удалённый шарик; после хода без удаления появляются до трёх новых шариков.
- Предпросмотр следующих цветов, новая игра и завершение партии при заполнении поля.
- Лучший счёт в localStorage; при недоступном хранилище игра продолжает работать с рекордом в памяти. Текущая партия не сохраняется.
- Адаптивная компоновка, CSS-анимации с учётом `prefers-reduced-motion`, кнопки клеток с aria-подписями и видимый клавиатурный фокус.

## Технологии

C#, .NET 8, Blazor WebAssembly, xUnit, HTML/CSS и минимальный JavaScript interop для localStorage. Приложение работает в браузере; отдельного backend и базы данных нет.

Текущая целевая платформа — **.NET 8**. Её поддержка завершилась **10 ноября 2026 года**, согласно [официальному объявлению Microsoft](https://devblogs.microsoft.com/dotnet/dotnet-8-9-end-of-support/). Запланирован переход на поддерживаемую LTS-версию .NET; в текущей версии миграция ещё не выполнена.

## Архитектура

| Проект | Ответственность |
| --- | --- |
| [Lines98.Core](src/Lines98.Core) | Неизменяемые `Board` и `GameState`, правила хода, генерация, поиск линий и начисление очков |
| [Lines98.Web](src/Lines98.Web) | Blazor-компоненты, `GameSession`, UI-состояние и хранение рекорда |
| [Lines98.Core.Tests](tests/Lines98.Core.Tests) | Тесты ядра и независимой от браузера логики сессии и рекорда |

`PathFinder` использует BFS: обход в ширину находит кратчайший путь по пустым клеткам с горизонтальными и вертикальными переходами. `LineFinder` сканирует четыре направления и объединяет позиции найденных линий, исключая повторный подсчёт пересечений.

`GameEngine` управляет полным ходом через `MoveService`, а `IScoreCalculator` отделяет правила начисления очков от поиска линий. `IRandomSource` позволяет подменять случайность для воспроизводимых тестов. `GameEngine.TryMove` возвращает состояние, признак успеха и причину отказа.

Интерфейс обращается к ядру через `GameSession`, не реализуя правила повторно. Выбранная клетка, подсветка и сообщения отделены от `GameState`. Тесты UI-независимых сервисов подключают их исходные файлы в существующий тестовый проект; тестов рендеринга компонентов нет.

## Локальный запуск

Понадобятся .NET SDK **8.0.428**, закреплённый в [global.json](global.json), и браузер с поддержкой WebAssembly. В `global.json` отключён roll-forward: другой установленный SDK не заменит указанную версию. Для разработки через IDE можно использовать Visual Studio 2022 с поддержкой ASP.NET и веб-разработки.

Из корня проекта:

```powershell
dotnet restore Lines98.sln
dotnet build Lines98.sln
dotnet test Lines98.sln
dotnet run --project src/Lines98.Web/Lines98.Web.csproj --launch-profile http
```

Откройте [http://localhost:5251](http://localhost:5251). В Visual Studio откройте [Lines98.sln](Lines98.sln), выберите `Lines98.Web` стартовым проектом и профиль `http`.

## Testing

Проверено 13 ноября 2026 года: **140 тестов прошли**, ошибок и пропусков нет. `dotnet build Lines98.sln` завершён без ошибок и предупреждений.

Тесты охватывают границы и неизменяемость доски, BFS, линии и пересечения, причины отказа хода, игровой цикл, генерацию, насыщение счёта, детерминированную случайность, выбор клеток, подсветку и логику рекорда.

Браузерный рендеринг, анимации и реальная доступность localStorage требуют ручной проверки. При запуске тестов возможно диагностическое сообщение VSTest об отсутствии `VSTEST_ARTIFACTS_DIRECTORY`; текущий набор тестов при этом проходит.
